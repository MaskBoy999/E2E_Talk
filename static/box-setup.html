E2E Chat

Enter the address of the machine running your E2E Chat server on Tailscale. You'll find it in the Tailscale admin console, or it's the address you use to open the chat in a browser.

Just the IP (or Tailscale machine name) is enough — https:// and port 3443 are added for you. Only include a port if your server uses a different one, e.g. 100.101.102.103:8443.

If it won't connect

  • Check the server is running on your host machine.
  • Open Tailscale on this device and make sure it's connected.
  • Confirm the address matches your host's Tailscale IP.
  • Make sure port 3443 isn't blocked by a firewall.
  • "Certificate changed" — you regenerated the server's cert. Tick Trust this server's certificate and save again.

The server uses a self-signed certificate. Trusting it pins its SHA-256 fingerprint: if the certificate ever changes without you re-trusting it here, the app refuses to connect.
